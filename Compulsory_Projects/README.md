# Python Projects Collection

This repository contains a collection of Python projects as part of the AI-101 course requirements. Each project demonstrates different Python programming concepts and features.

## Projects List

1. **Mad Libs** - A word game where players fill in blanks in a story with their own words
2. **Guess the Number (Computer)** - A game where the computer tries to guess a number you're thinking of
3. **Guess the Number (User)** - A game where you try to guess a number the computer has chosen
4. **Rock, Paper, Scissors** - The classic hand game implemented in Python
5. **Hangman** - A word guessing game where players try to guess a hidden word
6. **Countdown Timer** - A timer application that counts down from a specified time
7. **Password Generator** - A tool to generate secure random passwords
8. **BMI Calculator Web App** - A Streamlit web application to calculate Body Mass Index
9. **Streamlit Website** - A simple website built using Streamlit

## Setup Instructions

1. Clone this repository
2. Install required dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Navigate to the project directory you want to run
4. Run the Python file:
   ```
   python <project_name>.py
   ```

## Requirements

- Python 3.7 or higher
- Required packages are listed in requirements.txt
