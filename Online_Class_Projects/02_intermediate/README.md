# Intermediate Python Projects

This directory contains more advanced Python projects that build upon basic programming concepts and introduce new programming patterns and techniques.

For additional exercises and examples, check out our interactive Google Colab notebook:

## Project Structure

### Control Flow for Console
- **high-low.py**: An interactive number guessing game with advanced control flow

### Intro to Python
- **marsweight.py**: Calculate your weight on Mars
- **planetaryweight.py**: Extended planetary weight calculator for multiple planets

### Lists and Dicts
- **list_practice.py**: Exercises focusing on list manipulation
- **index_game.py**: Interactive game demonstrating list and dictionary usage

## Learning Objectives

- Advanced control flow concepts
- Working with complex data structures
- Implementing more sophisticated game logic
- Scientific calculations and conversions
- Error handling and input validation
- Code organization and structure

## Running the Projects

Navigate to the specific project directory and run:
```bash
python filename.py
```

## Prerequisites

- Completion of basic Python exercises
- Understanding of fundamental Python concepts
- Python 3.x installed on your system
