# Control Flow for Console Applications

This directory contains Python programs that demonstrate control flow concepts through console-based applications.

## Programs

1. **high_low_game.py**
   - Interactive number guessing game
   - Player competes against computer
   - Demonstrates:
     - Random number generation
     - User input handling
     - Score tracking
     - Multiple rounds
     - Conditional messages

## Learning Objectives

- Understanding control flow statements
- Working with random numbers
- Handling user input
- Implementing game logic
- Score tracking and round management
- Input validation

## Usage

Run the game using Python 3:
```bash
python high_low_game.py
```

## Game Rules

1. Two random numbers (1-100) are generated for player and computer
2. Player sees their number but not computer's
3. Player guesses if their number is higher/lower than computer's
4. Points awarded for correct guesses
5. Game continues for multiple rounds
6. Final score determines ending message
