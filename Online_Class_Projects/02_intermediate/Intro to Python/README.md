# Introduction to Python - Weight Calculators

This directory contains Python programs that calculate weights on different planets, demonstrating fundamental Python concepts through practical applications.

## Programs

1. **marsweight.py**
   - Calculates weight on Mars based on Earth weight
   - Demonstrates basic input/output
   - Shows number formatting and calculations

2. **planetaryweight.py**
   - Extended version that calculates weight on any planet
   - Uses dictionaries for gravity constants
   - Demonstrates conditional statements and data structures

## Learning Objectives

- Working with user input and output
- Performing mathematical calculations
- Using dictionaries for data lookup
- Formatting numeric output
- Basic error handling

## Usage

Run any program using Python 3:
```bash
python marsweight.py
# or
python planetaryweight.py
```
