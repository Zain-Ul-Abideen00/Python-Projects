# Lists and Dictionaries Practice

This directory contains Python programs focused on practicing list operations and data structure manipulation.

## Programs

1. **list_practice.py**
   - Basic list operations demonstration
   - Creating and manipulating fruit lists
   - Adding elements and checking list length

2. **index_game.py**
   - Interactive game for practicing list operations
   - Features:
     - Accessing elements by index
     - Modifying list elements
     - List slicing
     - Error handling
   - Mixed data type list manipulation

## Learning Objectives

- Understanding list creation and manipulation
- Working with list indices and slicing
- Error handling with try/except blocks
- User input validation
- Interactive program design

## Usage

Run any program using Python 3:
```bash
python list_practice.py
# or
python index_game.py
```
