## Programs Overview

### 1. Joke Bot (`00_joke_bot.py`)
A simple interactive bot that tells a programming joke when the user inputs "joke" (case-insensitive). Features:
- Type-annotated variables
- Case-insensitive input handling
- Constant definitions
- Basic if-else logic

### 2. Double It (`01_double_it.py`)
A program that takes a number input and keeps doubling it until it reaches 100 or greater. Features:
- While loop implementation
- User input handling
- Number manipulation
- Basic arithmetic operations

### 3. Liftoff Countdown (`02_liftoff.py`)
An interactive countdown program that simulates a rocket launch sequence. Features:
- Time-based delays
- For loop with range
- String formatting
- Visual feedback with emojis
- Interactive console output

### 4. Guess My Number (`03_guess_my_number.py`)
A number guessing game where the computer picks a random number and the user tries to guess it. Features:
- Random number generation
- While loop with break
- Conditional statements
- User input validation
- Interactive feedback

### 5. Random Numbers (`04_random_numbers.py`)
Generates and displays 10 random numbers between 1 and 100. Features:
- Random number generation
- For loop implementation
- Basic output formatting

## Running the Programs

Each program can be run independently using Python 3:

```bash
python program_name.py
```
