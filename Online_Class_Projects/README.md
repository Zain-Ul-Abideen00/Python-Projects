# Online Class Projects - Python Learning Repository

This repository contains a collection of Python projects and exercises organized into different difficulty levels, from basics to intermediate concepts. The projects are designed to help learners understand various Python programming concepts through hands-on practice.

## Google Colab Notebook
Access the interactive Google Colab notebook for additional exercises and examples:
[Python Learning Exercises](https://colab.research.google.com/drive/1yqfLJCfOspiyguTcJho5EOKeaJ4mYKQf?usp=sharing)

## Repository Structure

### 1. Basics (01_basics/)
A collection of fundamental Python programs covering basic concepts:

- **00_joke_bot.py**: A simple bot that tells jokes
- **01_double_it.py**: Program demonstrating basic number operations
- **02_liftoff.py**: Countdown program showcasing loops
- **03_guess_my_number.py**: Number guessing game implementation
- **04_random_numbers.py**: Introduction to random number generation
- **colab_code.md**: Additional code examples and documentation
- **README.md**: Basic section documentation

### 2. Intermediate (02_intermediate/)
More advanced Python concepts organized into three main sections:

#### Control Flow for Console
- **high-low.py**: Implementation of a high-low guessing game
- **exercises.md**: Practice exercises for control flow concepts
- **README.md**: Section-specific documentation

#### Intro to Python
- **marsweight.py**: Program to calculate weight on Mars
- **planetaryweight.py**: Extended version for multiple planets
- **exercises.md**: Introductory Python exercises
- **README.md**: Section documentation

#### Lists and Dicts
- **list_practice.py**: Basic list manipulation exercises
- **index_game.py**: Interactive game using lists and dictionaries
- **exercises.md**: Practice problems for lists and dictionaries
- **README.md**: Section-specific documentation

## Getting Started

1. Clone this repository to your local machine
2. Navigate to the desired project directory
3. Run the Python files using Python 3.x:
   ```bash
   python filename.py
   ```

## Project Categories

### Basic Projects
- Number manipulation
- Random number generation
- Simple games
- Basic input/output operations

### Intermediate Projects
- Control flow exercises
- List and dictionary manipulation
- Weight calculation programs
- More complex console games

## Prerequisites

- Python 3.x installed on your system
- Basic understanding of Python syntax
- Text editor or IDE of your choice

## Learning Path

1. Start with the basics folder (01_basics)
2. Progress through the programs in numerical order
3. Move to the intermediate section (02_intermediate)
4. Complete exercises in each subsection
5. Practice with the provided example programs
6. Use the Google Colab notebook for additional practice and examples
