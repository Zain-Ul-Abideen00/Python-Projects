# Python If Statements

This folder contains exercises focused on conditional statements and decision making in Python. Each program demonstrates different aspects of using if-else statements and conditional logic.

## Programs

1. **Print Events** (`01_print_events.py`)
   - Determines if numbers are even or odd
   - Uses modulo operator for checking even/odd status

2. **International Voting Age** (`02_international_voting_age.py`)
   - Checks if someone can vote based on their age and country
   - Demonstrates using dictionaries with conditional logic
   - Handles different voting age requirements by country

3. **Leap Year** (`03_leap_year.py`)
   - Determines if a given year is a leap year
   - Implements complex conditional logic for leap year calculation
   - Shows nested if statements

4. **Tall Enough to Ride** (`04_tall_enough_to_ride.py`)
   - Checks if someone meets height requirements for different rides
   - Uses dictionaries to store ride requirements
   - Demonstrates practical application of conditional statements

5. **Random Numbers** (`05_random_numbers.py`)
   - Generates and compares random numbers
   - Shows basic comparison operators
   - Introduces randomization with conditional logic

## Learning Objectives

- Understanding if-else statements and their syntax
- Working with comparison operators
- Implementing nested conditional statements
- Combining conditionals with other programming concepts
- Error handling with try-except blocks
