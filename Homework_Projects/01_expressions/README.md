# Python Expressions

This folder contains Python programs that demonstrate the use of various expressions and mathematical operations.

## Files Overview

1. `01_dicesimulator.py` - Simulates rolling a dice using random numbers
2. `02_e=mc2.py` - Calculates energy using Einstein's famous equation
3. `03_feet_to_inches.py` - Converts feet measurements to inches
4. `04_pythagorean_theorem.py` - Implements the Pythagorean theorem
5. `05_remainder_division.py` - Demonstrates remainder and division operations
6. `06_rolldice.py` - Another implementation of dice rolling
7. `07_seconds_in_year.py` - Calculates the number of seconds in a year
8. `08_tiny_mad_lib.py` - A simple mad libs game using string expressions

## Concepts Covered

- Mathematical expressions and operators
- Random number generation
- String formatting and manipulation
- Basic mathematical formulas
- Type conversion
- User input handling
- Arithmetic operations
- String concatenation and interpolation

## How to Use

1. Each Python file can be run independently
2. Follow the on-screen prompts for input
