# Python Dictionaries

This folder contains exercises focused on Python dictionaries. Each program demonstrates different aspects of working with dictionaries, including creation, manipulation, and common use cases.

## Programs

1. **Count Numbers** (`00_count_nums.py`)
   - Counts frequency of numbers in a list
   - Shows dictionary creation and updating
   - Demonstrates counting with dictionaries
   - Uses dictionary methods

2. **Phonebook** (`01_phonebook.py`)
   - Simple phonebook application
   - Shows CRUD operations with dictionaries
   - Demonstrates dictionary as a data store
   - Implements search functionality

3. **Pop-up Shop** (`02_pop_up_shop.py`)
   - Simulates a shop with inventory
   - Shows dictionary for inventory management
   - Demonstrates price calculations
   - Implements shopping cart functionality

4. **Powerful Passwords** (`03_powerful_passwords.py`)
   - Password strength checker
   - Shows dictionary for storing validation rules
   - Demonstrates complex validation logic
   - Implements scoring system

## Learning Objectives

- Understanding dictionary data structure
- Working with dictionary methods
- Implementing key-value pair operations
- Using dictionaries for data storage
- Managing complex data structures
- Implementing search and lookup operations
- Error handling with dictionaries

## Key Concepts

1. Dictionary Basics
   - Creation and initialization
   - Adding and updating items
   - Accessing values
   - Removing items

2. Dictionary Methods
   - `get()`
   - `items()`
   - `keys()`
   - `values()`
   - `update()`

3. Common Use Cases
   - Counting and frequency tracking
   - Data storage and retrieval
   - Configuration storage
   - Lookup tables
