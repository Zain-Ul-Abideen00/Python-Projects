# Python Loops and Control Flow

This folder contains exercises focused on loops and control flow in Python. Each program demonstrates different aspects of iteration, flow control, and program logic.

## Programs

1. **Guess My Number** (`00_guess_my_number.py`)
   - Interactive number guessing game
   - Demonstrates while loops
   - Shows user input validation
   - Implements game logic with conditionals

2. **Fibonacci** (`01_fibonacci.py`)
   - Generates Fibonacci sequence
   - Shows sequence generation with loops
   - Demonstrates list manipulation
   - Implements mathematical sequence

3. **Print Events** (`02_print_events.py`)
   - Prints even numbers in a range
   - Shows for loop with range
   - Demonstrates conditional statements
   - Uses modulo operator

4. **Wholesome Machine** (`03_wholesome_machine.py`)
   - Provides random positive affirmations
   - Shows infinite loop with break condition
   - Demonstrates random selection
   - Implements user interaction

5. **Liftoff** (`04_liftoff.py`)
   - Simulates countdown timer
   - Shows countdown with time delays
   - Demonstrates reverse loop
   - Uses time module

6. **Double It** (`05_double_it.py`)
   - Doubles numbers until reaching a limit
   - Shows while loop with condition
   - Demonstrates number sequence generation
   - Implements mathematical operations

## Learning Objectives

- Understanding different types of loops (for, while)
- Working with loop control statements (break, continue)
- Implementing conditional logic in loops
- Using loops with different data structures
- Managing program flow
- Handling user input in loops
- Implementing error checking

## Usage

1. Each program can be run independently
2. Follow the on-screen prompts for input
