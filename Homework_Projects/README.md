# Python Homework Projects

This repository contains a collection of Python programming exercises and projects organized by concepts. Each folder focuses on specific Python programming concepts and contains related exercises.

## Project Structure

- `00_intro_python/` - Introduction to Python basics
- `01_expressions/` - Python expressions and basic operations
- `02_lists/` - Working with Python lists and sequences
- `03_if_statements/` - Conditional statements and decision making
- `04_dictionaries/` - Python dictionaries and key-value pairs
- `05_loops_control_flow/` - Loops and control flow structures
- `06_functions/` - Python functions and modular programming
- `07_information_flow/` - Information flow and data handling

## Getting Started

Each folder contains:
- Python source files with exercises and solutions
- A README.md file explaining the specific concepts covered

## Requirements

- Python 3.x

## Usage

1. Navigate to the specific concept folder you want to study
2. Read the README.md file for concept overview
3. Review the Python source files for specific examples
4. Access the interactive learning environment through [Google Colab](https://colab.research.google.com/drive/1s2V-Yia12P-ZrfzVnle6YAAZi9d2whDD?usp=sharing)
