# Python Information Flow

This folder contains exercises focused on information flow and data handling in Python. The programs demonstrate different ways of passing data between functions and managing program state.

## Programs

1. **Choosing Returns** (`00_choosing_returns.py`)
   - Demonstrates different ways of returning values from functions
   - Shows handling of invalid inputs
   - Implements user choice selection

2. **Greetings** (`01_greetings.py`)
   - Generates time-based personalized greetings
   - Shows how to use datetime for conditional logic
   - Demonstrates string formatting

3. **In Range** (`02_in_range.py`)
   - Checks if a number falls within a specified range
   - Shows boolean return values
   - Implements input validation

4. **In Stock** (`03_in_stock.py`)
   - Manages inventory stock levels
   - Demonstrates tuple returns with status and message
   - Shows dictionary-based data management

5. **Multiple Returns** (`04_multiple_returns.py`)
   - Shows how to return multiple values from a function
   - Demonstrates tuple packing and unpacking
   - Analyzes different properties of a number

6. **Subtract 7** (`05_subtract_7.py`)
   - Demonstrates error handling with return values
   - Shows tuple returns for result and error states
   - Implements basic mathematical operations

## Learning Objectives

- Understanding function return values
- Working with multiple return values
- Implementing error handling patterns
- Managing program state
- Using tuples for compound returns
- Handling data flow between functions

## Usage
