# Python Lists

This folder contains Python programs that demonstrate the use of lists and list operations.

## Files Overview

1. `01_add_many_numbers.py` - Program to add multiple numbers using lists
2. `02_double_list.py` - Doubles the values in a list
3. `03_erase_canvas.py` - Demonstrates list manipulation with a canvas metaphor
4. `04_flowing_with_data_structures.py` - Shows data flow using list structures
5. `05_get_first_element.py` - Retrieves the first element from a list
6. `06_get_last_element.py` - Retrieves the last element from a list
7. `07_get_list.py` - Creates and manipulates lists
8. `08_shorten.py` - Demonstrates list slicing and shortening

## Concepts Covered

- List creation and initialization
- List indexing and slicing
- List methods and operations
- List manipulation
- List comprehension
- Iterating through lists
- List element access
- List modification techniques

## How to Use

1. Each Python file can be run independently
2. Follow the on-screen prompts for input
