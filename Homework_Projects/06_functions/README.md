# Python Functions

This folder contains exercises focused on Python functions. Each program demonstrates different aspects of function definition, parameters, return values, and function usage patterns.

## Programs

1. **Averages** (`00_averages.py`)
   - Calculates the average of a list of numbers
   - Demonstrates basic function structure
   - Shows list processing

2. **Chaotic Counting** (`01_chaotic_counting.py`)
   - Generates a sequence with random variations
   - Shows function parameters with default values
   - Demonstrates random number usage

3. **Count Even** (`02_count_even.py`)
   - Counts even numbers in a list
   - Shows boolean function usage
   - Demonstrates list comprehension

4. **Double** (`04_double.py`)
   - Simple function to double a number
   - Shows basic arithmetic operations
   - Demonstrates type handling

5. **Get Name** (`05_get_name.py`)
   - Gets and formats user input
   - Shows string manipulation
   - Demonstrates input handling

6. **Is Odd** (`06_is_odd.py`)
   - Checks if a number is odd
   - Shows boolean return values
   - Demonstrates modulo operation

7. **Print Divisor** (`07_print_divisor.py`)
   - Prints all divisors of a number
   - Shows loop usage in functions
   - Demonstrates mathematical concepts

8. **Print Multiple** (`08_print_multiple.py`)
   - Prints a string multiple times
   - Shows function with multiple parameters
   - Demonstrates loop usage

9. **Sentence Generator** (`09_sentence_generator.py`)
   - Generates random sentences
   - Shows complex string manipulation
   - Demonstrates random choice from lists

10. **Print Ones Digit** (`10_print_ones_digit.py`)
    - Extracts the ones digit from a number
    - Shows modulo operation
    - Demonstrates number handling

## Learning Objectives

- Understanding function definition and syntax
- Working with function parameters
- Implementing return values
- Using functions for code organization
- Handling different data types
- Implementing error checking
- Writing reusable code

## Usage

1. Each program can be run independently
