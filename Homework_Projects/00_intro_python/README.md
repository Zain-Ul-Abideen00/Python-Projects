# Introduction to Python

This folder contains basic Python programs that demonstrate fundamental programming concepts.

## Files Overview

1. `01_add_two_numbers.py` - A program that takes two numbers as input and calculates their sum
2. `02_agreement_bot.py` - A simple bot that interacts with user input
3. `03_fahrenheit_to_celsius.py` - Temperature conversion program
4. `04_how_old_are_they.py` - Age calculation program
5. `05_triangle_perimeter.py` - Calculates the perimeter of a triangle
6. `06_square_number.py` - Demonstrates square number calculations

## Concepts Covered

- Basic input/output operations
- Variable declaration and assignment
- Basic arithmetic operations
- Type conversion
- String formatting
- Basic function definition and usage

## How to Use

1. Each Python file can be run independently
2. Follow the on-screen prompts for input
3. For interactive learning, visit the [Google Colab notebook](https://colab.research.google.com/drive/1s2V-Yia12P-ZrfzVnle6YAAZi9d2whDD?usp=sharing)
